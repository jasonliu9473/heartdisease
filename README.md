# Heart Disease Exploratory Data Analysis

Classification analysis of the [UCI Heart Disease dataset](https://archive.ics.uci.edu/dataset/45/heart+disease) covering EDA, preprocessing, 5 classification algorithms, AUC-ROC evaluation, cross-validation, and feature importance.

## Dataset

- **Source:** UCI Heart Disease dataset (`dataset/raw.csv`)
- **Size:** 303 samples × 14 features
- **Target:** `target` — 0 (no disease) / 1 (disease)

| Feature | Type | Description |
|---|---|---|
| age | continuous | Age in years |
| sex | categorical | 0 = female, 1 = male |
| cp | categorical | Chest pain type (0–3) |
| trestbps | continuous | Resting blood pressure (mm Hg) |
| chol | continuous | Serum cholesterol (mg/dl) |
| fbs | categorical | Fasting blood sugar > 120 mg/dl |
| restecg | categorical | Resting ECG results (0–2) |
| thalach | continuous | Maximum heart rate achieved |
| exang | categorical | Exercise-induced angina |
| oldpeak | continuous | ST depression induced by exercise |
| slope | categorical | Slope of peak exercise ST segment |
| ca | categorical | Number of major vessels (0–3) |
| thal | categorical | Thalassemia type (1–3) |

## Preprocessing

Each algorithm receives a tailored preprocessed dataset generated by `preprocess.py`:

| Algorithm | Outlier Capping | Categorical Encoding | Feature Scaling |
|---|---|---|---|
| KNN | IQR | One-hot | StandardScaler |
| Logistic Regression | — | One-hot | StandardScaler |
| Random Forest | — | Ordinal (as-is) | — |
| Decision Tree | — | Ordinal (as-is) | — |
| SVM | IQR | One-hot | StandardScaler |

Run preprocessing:

```bash
python preprocess.py
```
